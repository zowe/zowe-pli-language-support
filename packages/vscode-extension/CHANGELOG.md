# PL/I Language Support Changelog

All notable changes to PL/I Language Support are documented in this file.

## 1.1.0 (TBA)

#### Added
- Quick Fix for unresolved include files
- Preliminary CICS and SQL preprocessor support
- Type reference support
- Enhanced macro preprocessor support

#### Fixed
- Miscellaneous bug fixes and performance improvements

#### Changed
- PL/I Language Support is now Zowe v3 conformant
- Readme update

## 1.0.3 (2025-10-16)

#### Added
- Enhanced compiler option support
- Enhanced macro preprocessor support
- Support for the `SQLCA` and `SQLDA` builtins
- Usage of builtin functions is now configurable in the PL/I plugin configuration
- JSON schema files for the configuration files

#### Fixed

- Miscellaneous bug fixes and performance improvements
